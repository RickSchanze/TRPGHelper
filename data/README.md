# data/ 内容配置

这里放的是**内容数据**（规则系统、素材、车卡流程、关键词、职业等级成长），全部是可以用 Excel 直接编辑的 xlsx。
文件名用中文，**工作表名保持英文**；玩家数据（用户、角色卡）不在这里，存在 SQLite。

| 文件 | 工作表 | 内容 |
| --- | --- | --- |
| `规则系统.xlsx` | `systems` / `attributes` | 规则系统（id、名称、姓名模板、图标 / 主色 / 是否开放）+ 属性模板（骰子公式） |
| `姓名片段.xlsx` | `names` | 姓名片段（分组：surname / given / first / epithet） |
| `职业.xlsx` | `classes` | 职业卡（描述、生命骰、主属性、配图、主色、特性） |
| `随机职业.xlsx` | `occupations` | 随机职业池 |
| `背景.xlsx` | `backgrounds` | 随机背景池 |
| `种族.xlsx` | `races` | 种族（属性加值、速度） |
| `职业灵感.xlsx` | `inspirations` | 车卡灵感（故事钩子） |
| `车卡流程.xlsx` | `steps` | 车卡流程步骤（选规则书不算步骤） |
| `职业等级.xlsx` | `levels` | 职业 1-20 级成长；`classId` 填中文职业名（也兼容英文 id），导出统一写中文 |
| `关键词分类.xlsx` | `categories` | 关键词分类编号（`id` 三位数字 + 名称），关键词 ID 的前三位 |\n| `关键词.<分类>.xlsx` | `keywords` | 关键词词条，**按分类拆文件**，每行带 `id`（8 位）与 `分类` 列 |

## 关键词 ID 与分类编号\n\n- 分类编号在 `关键词分类.xlsx` 里登记：`001 法术`、`002 职业`、`003 属性`、`004 规则`、`005 战斗`。\n- 关键词 ID = **分类编号（3 位） + 序号（5 位）**，例如 `00300001` 是属性分类的第 1 条。\n- `关键词.<分类>.xlsx` 每行的 `id` 列就是这个词的 ID；留空时加载会按分类顺序自动补号，导出后写回文件。\n\n## 关键词按分类拆文件

文件命名规则：`关键词.<分类>.xlsx`，分类可以带点表示多级：

```
关键词.属性.xlsx
关键词.规则.xlsx
关键词.战斗.xlsx
关键词.法术.一环.xlsx   → 分类是「法术.一环」
```

- 每行都有 `分类` 列，以列里的值为准；留空时用文件名里的分类。
- 新增一个分类只要新建一个 `关键词.<新分类>.xlsx`，表头和现有文件一致即可，不用改代码。
- 导出时按 `分类` 列分组，自动生成对应文件；没有分类的词条写进 `关键词.未分类.xlsx`。

## 改内容的两种方式

1. **直接改 xlsx**（推荐）：改完重启后端，启动时会把文件整份同步进数据库。
2. **在管理台里改**：改完点「概览 → 导出内容到 data/」，把数据库里的内容写回这些 xlsx；否则下次启动会被文件覆盖。

## 约定

- 跨表引用一律用 id：`systemId` 指 `规则系统.xlsx > systems > id`，`classId` 指 `职业.xlsx > classes > id`。
- 行的上下顺序就是展示 / 抽取顺序，不需要额外的排序列。
- `isEnabled` / `available` 填 `是` / `否`（也接受 true/false、1/0），留空默认「是」。
- 文本里的 `[关键词]` 会由前端渲染成可点击的关键词。
- 职业卡配图 `imageUrl` 可以填 `/static/classes/xxx.jpg`（前端打包资源）或上传后的 `/uploads/xxx.png`。

字段级说明见 [docs/content-format.md](../docs/content-format.md)。
