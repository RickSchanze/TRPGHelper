## 1. 现状：现在能车到哪

车卡流程（`data/车卡流程.xlsx`，可在管理台配置）：

| 步骤 | 现在做了什么 | 产出 |
| --- | --- | --- |
| 选择职业 | 5 张职业卡：游侠 / 战士 / 武僧 / 德鲁伊 / 圣武士；展示生命骰、主属性、描述、特性文案、配图 | `className` |
| 选择子职 | 只有圣武士的 3 个神圣誓约（奉献 / 古贤 / 复仇）；其它职业提示可跳过 | `subclassName` |
| 选择种族 | 9 个核心种族，展示属性加值、速度、描述、特质（`[关键词]` 可点） | `raceName` |
| 选择亚种 | 19 个亚种（精灵 3、矮人 2、半身人 2、侏儒 2、龙裔 10） | `subraceName` |
| 决定背景 | 目前只有阵营（九宫格 9 个） | `alignmentName` |
| 决定属性 | 空手填或「投掷」一组 4d6 取高 3；初始 + 种族 / 亚种加值，点每项看来源 | `sheet.attributes[]` |

内容家底（`data/`）：

- 职业 5、子职 3、种族 9、亚种 19、阵营 9、背景 10（**只有名字**）
- 职业等级 127 行（5 个职业 1–20 级，是文字说明，不是可选项）
- 关键词 223 条，分类：法术 / 职业 / 属性 / 规则 / 战斗 / 种族 / 阵营
- 姓名片段 100 条、车卡灵感 20 条、随机职业/背景池

卡面/接口现在能存：

- `CharacterCard`：名字、职业、子职、种族、亚种、阵营、年龄、简介、头像、状态、收藏
- `CharacterSheet`：属性、技能、物品、背景（字符串）、备注
- 创建流提交时：随机生成名字 → 写入职业/子职/种族/亚种/阵营/属性；`skills` 和 `items` 一直传空

已经算出来但**没写进卡**：生命值上限、无甲 AC、先攻、被动察觉（只作为「决定属性」面板底部的小结）。

## 2. 书里创建角色的 6 步 × 现状

| 书里的步骤 | 书里要求 | 现在有 | 主要缺口 |
| --- | --- | --- | --- |
| 1 选择种族 | 种族 + 亚种；属性加值、速度、体型、语言、黑暗视觉等特质、部分武器/护甲/技能熟练、戏法 | 种族 / 亚种卡、属性加值、速度、特质文案 | 语言选择、种族给的熟练项落地（如精灵武器、矮人护甲、半兽人威吓、半身人幸运）、体型、种族戏法 |
| 2 选择职业 | 生命骰、豁免熟练、护甲/武器/工具熟练、技能选择（从列表选 N 个）、1 级特性、起始装备、施法 | 职业卡、生命骰、豁免/施法属性数据（**未使用**）、特性文案 | **技能选择**、**起始装备**、1 级特性选择（战斗风格/宿敌/自然探索者）、熟练项结构化、法术 |
| 3 决定属性 | 4d6 取高 3 / 标准数组 / 点数购买（变体）；加种族加值；算调整值 | 已实现（手填 + 投掷 + 来源） | 点数购买（目前不需要）、属性上限提示 |
| 4 描述角色 | 姓名、性别、年龄、身高体重、外貌（眼睛/头发/肤色）、阵营、理想/牵绊/缺点、背景 | 阵营；年龄字段（不在流程里）；简介可写；名字随机 | **姓名步骤**、性别/外貌/身高体重、**背景本身**、理想/牵绊/缺点/性格 |
| 5 选择装备 | 职业起始装备包 **或** 起始金币；武器/护甲/盾/工具；AC 按护甲算；负重 | 无 | **整套装备系统**、AC 计算、攻击加值/伤害、负重/金币 |
| 6 集结 | 角色之间怎么认识、队伍目标（DM 协作） | 无 | 可选，后面再考虑 |

## 3. 缺口清单（按"能不能上桌"排）

### P0：让一张卡能上桌

1. **背景（真正的背景，不是只有名字）**
   - 现在 `data/背景.xlsx` 只有 10 个名字，其中「平民 / 学徒 / 佣兵 / 流浪者」不是 2014 PHB 背景；PHB 13 个里缺 **侍僧 / 公会工匠 / 化外之民 / 平民英雄 / 智者 / 流浪儿 / 骗子**（现有「平民」≈ 平民英雄、「流浪者」≈ 化外之民，需要统一译名）。
   - 每个背景要补：2 个技能熟练、工具熟练、语言、装备、背景特性、d8 性格 / 理想 / 牵绊 / 缺点表（结构见[士兵](https://github.com/DND5eChm/5echm_web/blob/pages/topics/%E7%8E%A9%E5%AE%B6%E6%89%8B%E5%86%8C/%E4%B8%AA%E6%80%A7%E4%B8%8E%E8%83%8C%E6%99%AF/%E5%A3%AB%E5%85%B5.html)）。
   - 产品上建议把「决定背景」变成：先选背景（卡片）→ 再选阵营；或者按书把阵营挪到「描述角色」那一步。
2. **技能（熟练项）**
   - 18 项技能与属性对应：力量-运动；敏捷-体操、巧手、隐匿；智力-奥秘、历史、调查、自然、宗教；感知-驯兽、洞悉、医药、察觉、生存；魅力-欺瞒、威吓、表演、说服。
   - 职业给"从列表选 N 个"：游侠 3、战士 2、武僧 2、德鲁伊 2、圣武士 2；背景固定 2 个；种族/专长可能再补。
   - 需要技能选择 UI、把 `sheet.skills` 填上（带熟练标记），并影响被动察觉等数值。
   - 现在关键词里只有「隐匿」一个技能词条，技能列表本身没有内容。
3. **语言**
   - 种族母语（通用语 + 精灵语/矮人语/龙语…）、背景/职业的额外语言（如侍僧 2 门、智者 2 门、贵族 1 门）。
   - 需要语言列表、选择 UI、持久化；现在卡面完全没有语言字段。
4. **装备与战斗数值**
   - 职业起始装备包（或起始金币）；武器（攻击加值/伤害/属性）、护甲（轻甲 + 敏捷、中甲敏捷上限 2、重甲固定、盾 +2）、工具、装备包。
   - 需要：`装备.xlsx`（护甲/盾/武器/工具/包）、装备选择步骤、AC 计算、攻击加值与伤害、负重/金币（可选）。
   - 卡面要落：生命值上限（生命骰最大 + 体质）、AC、先攻、速度、豁免加值、熟练加值 +2、被动察觉。
5. **姓名 / 性别 / 年龄 / 外貌**
   - 现在名字是后端随机生成，没有起名步骤；年龄只在模型里。
   - 需要：姓名（随机 + 手填）、性别、年龄、身高/体重、眼睛/头发/肤色、形象描述。
6. **1 级特性选择**
   - 战士「战斗风格」、游侠「宿敌 + 自然探索者」是 1 级就要选的；德鲁伊「德鲁伊语」自动获得；圣武士 1 级没有选择。
   - 需要把特性做成结构化选项（不是一段文案），并在车卡里选、写进卡面。
7. **卡面展示**
   - 详情页现在只显示：名字、一行元信息、简介、属性、技能、日志。
   - 缺：背景、语言、熟练项、装备、特性、HP/AC/先攻/速度/豁免、法术。
   - 卡库列表也只有名字/状态/简介。

### P1：把施法职业和子职补完整

8. **法术（1 级就能施法的只有德鲁伊）**
   - 德鲁伊 1 级：2 个戏法、2 个 1 环法术位、准备 `感知调整值 + 等级` 个法术；法术豁免 DC = 8 + 熟练 + 感知，法术攻击加值 = 熟练 + 感知。
   - 游侠 / 圣武士 2 级才有施法，属于升级流程。
   - 需要：`法术.xlsx`（戏法 + 1 环法术）、职业法术列表、法术选择 UI、卡面法术页。
9. **子职补齐**
   - 现在只有圣武士 3 个誓约；战士范型、游侠范型、武僧宗派、德鲁伊结社都还在"整理中"，流程里会跳过。
10. **职业特性结构化**
    - `职业等级.xlsx` 127 行是文字说明（"属性值提升"、"法术位提升"等），做升级/卡面特性列表前需要结构化成"等级 + 特性 + 是否可选 + 关键词"。

### P2：规则完整度与升级

11. **专长 / 属性值提升**（4/8/12/16/19 级）：车 1 级用不到，但升级要用；数据与流程都要加。
12. **背景个性表**：理想 / 牵绊 / 缺点 / 性格，可随机也可自选（背景页的 d8 表）。
13. **变体规则**：27 点点数购买、变体人类、专长替代属性提升、多职业、负重/货币。
14. **升级流程**：等级 / 经验、HP 成长、法术位、子职等级特性；以及角色卡导出 / 分享。

## 4. 数据、接口、模型要怎么补

### 新增内容文件（建议）

| 文件 | 内容 |
| --- | --- |
| `背景.xlsx` | 背景主表（技能、工具、语言、装备、特性）+ 个性表（d8 性格/理想/牵绊/缺点） |
| `技能.xlsx` | 18 项技能：key / 名称 / 关联属性 / 说明 |
| `语言.xlsx` | 标准语 + 异界语，供种族/背景/职业发放 |
| `装备.xlsx` | 护甲（类型/AC 算式/力量要求/隐匿劣势）、盾、武器（伤害/属性/熟练类别/特性）、工具、装备包、金币 |
| `法术.xlsx` | 0 环/1 环法术（名称、学派、施法时间、距离、成分、持续时间、描述、职业列表） |
| `职业特性.xlsx` | 各职业 1 级特性与可选选项（战斗风格、宿敌、自然探索者…），替代现在 `职业等级.xlsx` 里的文字 |
| `专长.xlsx`（P2） | 专长与前置条件 |

### 模型 / 接口

- `CharacterCard` 或 `CharacterSheet` 要扩：`backgroundCode/Name`、`level`、`xp`、`speed`、`hitPoints{max,current,temp}`、`armorClass`、`initiative`、`proficiencyBonus`、`savingThrows[]`、`languages[]`、`proficiencies{armor,weapons,tools}`、`equipment[]`、`spells{known,prepared,cantrips,slots}`、`personality{traits,ideals,bonds,flaws}`、`physical{gender,height,weight,eyes,hair,skin}`。
- 新接口：`/api/generator/backgrounds`、`/skills`、`/languages`、`/equipment`、`/spells`、`/class-options`；`POST/PUT /api/characters` 扩字段；详情 DTO 加卡面区块。
- 管理台：给背景、技能、语言、装备、法术、职业特性都做维护页，并接上导出回 xlsx（沿用现在的"内容以 data/ 为准"）。

## 5. 建议的迭代顺序

| 迭代 | 内容 | 理由 |
| --- | --- | --- |
| A. 背景与描述 | 背景数据 + 背景选择、技能选择、语言、姓名/性别/年龄/外貌、卡面展示这些内容 | 不涉及战斗数值，先把"角色是谁"填完整 |
| B. 装备与战斗数值 | 起始装备/金币、武器护甲盾、AC/攻击/HP/豁免/熟练/被动察觉写进卡面、负重 | 让卡能真的上桌打架 |
| C. 法术与子职 | 德鲁伊 1 级法术、4 个职业的子职、1 级特性选择项 | 把施法职业和子职流程补完整 |
| D. 升级与扩展 | 等级/XP、专长、属性提升、多职业、点数购买、导出/分享 | 车完卡之后的事 |

## 6. 顺手记的细节 / 坑

- **2014 vs 2024**：不全书里同时有 2024 试读版。2014 是"种族给属性加值、背景给技能/工具/语言、没有背景加值"；2024 改成"背景给属性加值、种族不加值、无亚种"。现在数据是 2014，别混用。
- **阵营位置**：书里阵营属于第 4 步「描述你的角色」，现在它占了「决定背景」；功能上没问题，但和「背景」概念重叠，建议明确分工。
- **背景名单不一致**：现有 10 个背景名和 PHB 13 个对不上（见 P0-1）。
- **游侠施法属性是空的**：`职业.xlsx` 里 `spellcastingAbility` 只有德鲁伊（感知）和圣武士（魅力）有值；游侠 2 级才施法，数据上应该也是感知，补法术时要一起补。
- **技能词条几乎没有**：关键词库里只有「隐匿」，其余技能要在 `关键词.规则.xlsx` 或新 `关键词.技能.xlsx` 里补。
- **`CharacterSheet.Background` 是自由字符串**，现在没用上；做背景时建议改成 code + 名称。
