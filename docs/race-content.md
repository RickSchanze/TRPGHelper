# 种族内容生成脚本

`tools/build_race_content.py` 负责生成 DND 5E 九个核心种族的展示数据与词条，保证「脚本 → xlsx」可复现。

## 产出

| 文件 | 脚本改什么 |
| --- | --- |
| `data/关键词分类.xlsx` | 确保 `种族` 分类存在（当前编号 `006`）；缺了就按现有最大编号 +1 分配并写回 |
| `data/关键词.种族.xlsx` | 整份重写：9 条种族词条 + 20 条特质词条（`key` = 种族名 / 特质名，ID = 分类号 + 五位序号） |
| `data/关键词.规则.xlsx` | 只补缺的词条：速度 / 体型 / 年龄 / 语言（已有同名词条时跳过，不动其它行） |
| `data/种族.xlsx` | 写 `description`、`abilityBonus`、`traits` 三列（按种族名匹配），其它列和其它种族不动 |

脚本不改别的文件，也不碰玩家数据。

## 写法：和职业卡一致

职业卡的特性是 `[宿敌]：选定一类宿敌…` 这种「`[关键词]` + 说明」的写法，种族卡照抄：

- `description`：一句话定位，里面直接嵌 `[关键词]`，例如精灵是「敏捷而敏锐，天生拥有`[黑暗视觉]`与`[妖精血统]`。」
- `abilityBonus`：属性加值也带方括号，例如「`[敏捷]` +2」「`[力量]` +2、`[魅力]` +1」。
- `traits`：一行一条，形如「`[关键词]`：说明」，例如「`[妖精血统]`：对抗`[魅惑]`有优势」；速度、体型、年龄、语言、亚种这些通用词也各自是词条。
- 所有出现在方括号里的名字都必须在词条库里登记，否则前端会把方括号原样显示出来。脚本把 9 个种族、20 个特质（含`亚种`）写进 `关键词.种族.xlsx`，把`速度`/`体型`/`年龄`/`语言`补进 `关键词.规则.xlsx`；引用别的分类的词条（`[魅惑]`、`[豁免]`、`[黑暗术]` 等）时，先确认 `data/关键词.*.xlsx` 里已经有。

## 可选规则：任意两项 +2 / +1

种族面板顶部有个可选开关「任意两项 +2 / +1」：

- 关闭（默认）：卡片显示各族的固定属性加值，即 `种族.xlsx > abilityBonus` 的内容。
- 打开：所有种族统一改为「自选两项属性分别 +2 / +1」，卡片上的固定加值换成 `[属性值加成]：任意两项 +2 / +1`，卡面不再显示固定的「属性值加成」那一条。
- 说明：每个种族的词条 `content` 末尾都写了这条可选规则，点开词条能看到；开关状态存在本机草稿里（`houseRuleAbilityScores`），不影响服务端数据。

## 依赖

- Python 3
- `openpyxl`：`pip install openpyxl`

## 用法

```powershell
# 重新生成
python tools/build_race_content.py

# 只校验现有 xlsx 和脚本是否一致（不一致时退出码为 1，可用于 CI / 提交前检查）
python tools/build_race_content.py --check
```

跑完建议重启后端，内容才会重新同步进 SQLite。

## 内容来源与约定

- 取材：**5E 不全书 · 玩家手册（2014）· 种族**，例如
  [人类](https://5echm.kagangtuya.top/topics/%E7%8E%A9%E5%AE%B6%E6%89%8B%E5%86%8C/%E7%A7%8D%E6%97%8F/%E4%BA%BA%E7%B1%BB.html)、
  [精灵](https://5echm.kagangtuya.top/topics/%E7%8E%A9%E5%AE%B6%E6%89%8B%E5%86%8C/%E7%A7%8D%E6%97%8F/%E7%B2%BE%E7%81%B5.html)。
  译名约定见 [translation.md](translation.md)。
- `summary` 一句话结论，**不能含 `[方括号]`**（`ContentLoader` 会校验），最多 256 字。
- `content` 是完整特质，可以嵌 `[黑暗视觉]`、`[妖精血统]`、`[抗性]` 这类已登记词条；没登记的词条前端会原样显示 `[关键词]`，所以新增引用前先确认词条库里有。
- `traits` 是种族卡上逐条展示的特质，同样支持 `[关键词]`，一行一条。
- 2024 版《玩家手册》的物种表不是这套（是阿斯莫、歌利亚等 10 个），仓库当前按 2014 版走。

## 改内容的两种方式

1. **改脚本（推荐）**：编辑 `RACES` 常量 → 重跑 → `--check` 通过 → 重启后端。
2. **管理台改完导出**：管理台「关键词」页签改完，点「概览 → 导出内容到 data/」写回 xlsx。

两种方式会互相覆盖：脚本重跑会盖掉管理台导出的种族词条与 `traits`，管理台导出也会按库里的内容重写 `关键词.种族.xlsx`。改之前先确认以哪边为准。
