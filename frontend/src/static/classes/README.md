# 职业素材

「车新卡」第二步的职业技能卡会用到这里的配图。

## 替换方法

1. 同名覆盖：`ranger.jpg`（游侠）、`fighter.jpg`（战士）、`monk.jpg`（武僧）、`druid.jpg`（德鲁伊）、`paladin.jpg`（圣武士），建议 16:9 横图，1200px 宽左右；
2. 路径和主色在仓库根目录 `data/generator.xlsx > classes` 的 `imageUrl` / `accent` 列配置（也可以用管理台上传图片），前端不再硬编码。

卡片按 16:9 完整显示图片（`aspectFit`，不裁切）；比例不是 16:9 时会在深色底上留边，不会切掉人物。

## 当前素材

`ranger.jpg` / `fighter.jpg` / `monk.jpg` / `druid.jpg` / `paladin.jpg`：开发期临时使用的职业插图（用户提供），正式版请替换为自有素材。
