# 子职配图

车卡流程第二步「选择子职」的卡片配图，文件名与 `data/子职.xlsx` 的 `imageUrl` 对应：

| 文件 | 子职 |
| --- | --- |
| `paladin-devotion.jpg` | 奉献之誓 |
| `paladin-ancients.jpg` | 古贤之誓 |
| `paladin-vengeance.jpg` | 复仇之誓 |

建议 16:9（例如 1536×864），主体居中偏右，左侧留一点暗部给文字压暗用；不要在图里带文字或边框。

生成提示词见仓库 `docs/image-prompts.md`。换图直接同名覆盖即可；想换路径就改 `子职.xlsx` 的 `imageUrl`（管理台也能上传到 `/uploads/...`）。
